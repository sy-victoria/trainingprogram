# 作业完成情况与差距

截至 2026-11-16，以真实运行记录为准。

这是扩大范围之前的先导阶段记录。2026-11-17 起，当前范围及欠项以 [完整版计划](FULL_EXPERIMENT_PLAN.md)和[开发进度](FULL_STUDY_PROGRESS.md)为准；Qwen3.8-27B 已确认，且纳入正式模型清单。

## 第一部分：Coding / SWE Agent

已实现 LangGraph coding agent，提供文件列表、读取、搜索、补丁和测试五类 ACI 工具；命令行 run/resume/status；SQLite checkpoint；修改前批准、拒绝与反馈；任务独立目录、调用预算、模型与工具日志；路径越界拦截、重复补丁防护、恢复时文件状态检查、工具超时。机制测试与真实模型结果分开记录。

4B BF16 真实完成三个自建 Python 修复任务：质数边界、空列表平均值、保持顺序且支持不可哈希元素的去重。三项均通过独立隔离验收，各 3 个测试；模型调用分别为 4、4、10 次。真实演示了暂停后恢复、审批、拒绝反馈及再次审批。审批为用户授权的代理审批，不是用户逐项人工点击，也不是无人干预成功率。

Qwen-Agent 与 Deep Agents 各有最小示例，已真实连接同一份 4B BF16，读取同一文件并正确指出 bug。已有框架机制比较，但它们没有实现主 Agent 的完整修改、审批和恢复流程，因此不能声称完成了三套完整 Agent 的公平效果评测。

差距：尚未逐项对齐某个公开 Coding/SWE Agent 的算法与实验设置；当前是基于框架的自主实现及功能复现。如果课程的“复现”要求指定论文或开源项目，需要补充复现对象和偏差说明。任务只有三个小型自建任务，未跑 SWE-bench 或真实大型仓库 issue。ACI 为本项目自行实现的交互工具层，未接入独立外部 ACI 产品；是否需要外部产品需看课程对该术语的定义。

## 工程交付与实验限制

源码位于服务器 /home/sunyue/trainingprogram，大型权重和产物位于 /backup/trainingprogram-data。模型下载、转换、量化、服务、冒烟、正式评测、日志和导出流程均已实现。服务器没有可用 Docker 权限，实际使用经过机制验证的 bubblewrap + systemd 做隔离和资源限制，没有静默回退到无隔离执行。
